\# Dataset



This project uses the \*\*Online Retail Dataset\*\* from the UCI Machine Learning Repository.



\## Source



UCI Machine Learning Repository — Online Retail Dataset



https://archive.ics.uci.edu/dataset/352/online+retail



\## Dataset Description



The dataset contains transactional data from a UK-based online retailer between \*\*December 1, 2010 and December 9, 2011\*\*.



Main columns include:



\- `InvoiceNo`

\- `StockCode`

\- `Description`

\- `Quantity`

\- `InvoiceDate`

\- `UnitPrice`

\- `CustomerID`

\- `Country`
